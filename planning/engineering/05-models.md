# Hardware detection, model registry and downloads

## Honest compatibility policy

The standalone upstream's documented starting point is **Linux, NVIDIA BF16, 24 GB VRAM**; its RTX 4090 measurements show ~11 GiB VRAM in some cases and ~14 GiB in maximum-context tests. These are **not** Windows or ComfyUI memory measurements. The primary ComfyUI backend has two published [Comfy-Org checkpoints](https://huggingface.co/Comfy-Org/YuE2/tree/main/checkpoints): `yue2_3b_int8_convrot.safetensors` (3,960,938,800 download bytes) and `yue2_3b_bf16.safetensors` (7,799,983,228 bytes), each packaged for ComfyUI with the model/audio VAE. The smaller **file** is not proof of 4 GB or 8 GB **peak working VRAM**; score/semantic generation, sampler and VAE all consume memory. Neither standalone `YuE2-Vae-legacy` nor SheetSage2 is a substitute for the generator.

## Registry (versioned, shipped with app)

Each selectable entry contains: display name, backend, purpose (generator/transcriber/lyric model), source URL/repo and pinned revision, file hashes, exact runtime dependency, license URL/acceptance state, disk estimate, **estimated VRAM requirement plus safety margin**, host RAM, a brief end-to-end compatibility check and compatibility graph. Initial **candidate** profiles: Comfy-Org int8 combined checkpoint (preferred default *if working*) and bf16 combined checkpoint (Advanced option), both requiring a pinned ComfyUI runtime. Cover jobs add the `sheetsage2_bf16.safetensors` audio encoder from the same repo; confirm its actual downloaded dependency graph. No separate YuE2 VAE download is needed with these combined checkpoints. Seek a real further low-memory solution for 8 GB and, if feasible, 4 GB; neither available file alone is labeled as such. Advanced settings may show experimental profiles labeled as such, never silently substitute them.

## First-run selection algorithm

1. Read dedicated total VRAM via Windows DXGI (NVIDIA NVML optional), check driver/CUDA/BF16 support and available host RAM/disk. Prefer the user's discrete NVIDIA GPU if multiple adapters exist. Free VRAM is useful for runtime OOM warnings, not the primary model-choice signal.
2. Filter compatible registry profiles and choose by a **simple conservative heuristic**: available validated 4 GB class for ~4–<8 GB cards, 8 GB class for ~8–<16 GB, and larger/full profile for >=16 GB **only if its stated requirements actually fit**; otherwise try the next smaller real profile. These class names are targets, not claims that YuE2 runs at those sizes. Apply reserve and required feature checks. A user-selected profile can override preference with an explicit risk warning; recheck free space/VRAM before generation and handle OOM without crashing.
3. If no compatible profile exists, do not invent/download a model. Explain the requirement and offer player-only mode. With current official evidence, an >=16 GB heuristic is not itself proof of support; a given full profile may still require 24 GB.
4. On first **app start**, present the recommendation, source, storage path, sizes, third-party license and explicit consent before automatic download. If no compatible profile, offline or declined, defer setup and allow playback. For a ComfyUI profile download its **combined** checkpoint, and add the SheetSage2 audio encoder only for covers; download any additional dependencies only if the pinned graph truly needs them. Lyric model downloads are separate and opt-in. Use a resumable Hugging Face client where possible, staging files and checking expected hashes before atomic install. Support retry/cancel, free-space checks, offline cache verification, removal and download progress.
5. Switching profiles in Advanced Settings triggers the same confirmation and managed download, preserving other cached profiles until user chooses cleanup. Display active model, actual revision and loaded-device memory. Never fetch executable packages by arbitrary untrusted user URL.

Model weights have separate licenses from this repo's MIT license. Upstream YuE2 code is Apache-2.0; YuE2 weights use CC BY-NC 4.0 plus an individual-creator permission for monetized outputs, **not blanket commercial company usage or unrestricted weight redistribution**. Check **ComfyUI and its dependencies' own licenses** before embedding a runtime. SheetSage2/MERT and optional community models have their own terms. Link terms in-app and review any bundled binaries, FFmpeg distribution, audio codecs and third-party notices before release.
